# POP V0.1 Scope

V0.1 proves that a small always-on-top Windows companion can receive minimum structured context from
explicitly authorized VS Code and Chrome integrations, offer explain/improve actions, make deliberate
Groq requests, and clearly show what it can see and when data leaves the computer.

## Included

- Tiny, compact, and expanded companion modes with monitoring control and tray behavior
- Local settings, deny-by-default app/domain policy, and foreground-application identity
- Versioned localhost communication with strict validation and reconnection
- VS Code selected-code explanation
- Approved-domain Chrome text explanation and writing improvement
- Provider-neutral AI interface with one Groq implementation
- Cloud activity, privacy visibility, safe logging, cancellation, and focused security tests

## Excluded

Continuous screenshots, OCR, global keylogging, voice, camera, long-term memory, filesystem RAG, MCP,
agent loops, autonomous posting, terminal execution, mouse/keyboard control, telemetry, accounts,
payments, and cloud persistence are explicitly outside V0.1.

## Phase 0 acceptance

- The Git repository and pnpm workspace exist.
- Directory ownership and dependency direction are documented.
- Shared formatting, linting, strict type checking, tests, and Windows CI pass.
- Secrets and build output are ignored.
- Native prerequisites are identified without implementing Phase 1.
