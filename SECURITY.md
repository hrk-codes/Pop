# Security Policy

## V0.1 principles

POP uses least privilege, deny-by-default permissions, minimum necessary context, visible cloud
activity, and explicit user control. Context must be checked and sanitized before it can reach the
event engine or an AI provider.

## Reporting a vulnerability

Do not open a public issue containing credentials, private user content, or exploit details. Contact
the project owner privately. A dedicated security contact will be published before a public release.

## Supported versions

The project is pre-release. Only the current development version will receive security fixes.
